# LC_PFAS

Autoencoder-based analysis of liquid crystal droplet array images for detecting PFAS (PFOA and PFOS) in water.

## Contents
- `data/`: image data
- `model_training/`: autoencoder training
- `model_analysis/`: analysis of the latent space
- `notebooks/`: notebooks
