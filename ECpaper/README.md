# ECpaper

Case studies using the Euler characteristic (EC) as a topological descriptor for complex data. Each folder has a Jupyter notebook that reproduces one case study:
- `2d_random_field/`: EC of 2D random fields and images
- `Brain Analysis/`: brain connectivity data
- `Eastmann/`: Tennessee Eastman process data
- `Flow_Cytometry/`: flow cytometry data
- `LC_Analysis/`: optical responses of liquid crystals
- `Reaction_Diffusion_Analysis/`: reaction–diffusion patterns
