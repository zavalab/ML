# Data Folder

This folder contains the canonical train/test split files used by the TDA4Protein pipeline.

## Included Files

```text
data/
  README.md
  dataset_split_manifest.csv
  splits/
    training.txt
    testing.txt
```

## Protein CSV Files

The protein surface CSV files are not committed directly to GitHub because the folder contains thousands of files. They are provided separately as `protein_csvs.zip'.
