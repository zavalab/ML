# CurriculaGraphs

Interactive graphs of the topics in core chemical engineering courses and the modules they form. Open the HTML files in a web browser:
- `Topics in Core Courses.html`
- `Modules of Topics in Core Courses.html`

## Reference
These graphs accompany the paper:

Blake Lopez, Yue Shao, and Victor M. Zavala. "A graph-theoretic framework for analyzing and designing chemical engineering curricula." *Computers & Chemical Engineering* 200 (2025): 109150. https://doi.org/10.1016/j.compchemeng.2025.109150

Preprint: https://doi.org/10.26434/chemrxiv-2024-stm40
