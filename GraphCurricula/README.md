# GraphCurricula

Graph-theoretic analysis and design of chemical engineering curricula: tutorial and UW–Madison study with course, curriculum, and transport graphs.

## Contents
- `Tutorial/`: tutorial with data, notebooks, and course and curriculum graphs
- `UWMadison-Study/`: the UW–Madison case study with data, notebooks, course, curriculum, and transport graphs, and animations

## Reference
