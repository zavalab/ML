# DynamicCatalysis

Simulation and Bayesian optimization of programmable (dynamic) catalysts, in which the catalyst's binding energies are switched over time to accelerate surface reactions.

## Contents
- `ProCatPy/`: Python model of a programmable catalytic system (`ProCatSystem.py`)
- `Basic Network/`: simulations and visualizations of an A → B surface reaction network (Sabatier plots, surface-concentration heatmaps, animation)
- `TutorialFiles/`: a basic tutorial (`BasicTutorial.ipynb`) and a Bayesian optimization tutorial (`BOTutorial.ipynb`)
