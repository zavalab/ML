# ImageMPC

Image-based model predictive control of a 2D heat diffusion system using dynamic mode decomposition (DMD) models, compared with standard MPC.

See `readme.txt` for a description of each script (MATLAB for training the DMD and standard models, Julia for the MPC designs).

## Reference
This code accompanies the paper:

Qiugang Lu and Victor M. Zavala. "Image-based model predictive control via dynamic mode decomposition." *Journal of Process Control* 104 (2021): 146-157. https://doi.org/10.1016/j.jprocont.2021.06.009

Preprint: https://arxiv.org/abs/2006.06727
