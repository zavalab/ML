# LC_CNN_Color

Convolutional neural network analysis of color optical micrographs of liquid crystal sensors exposed to different chemical environments.

## Contents
- `Jupyter_Notebooks/`: notebooks and image data

## Reference
This code accompanies the paper:

Alexander D. Smith, Nicholas Abbott, and Victor M. Zavala. "Convolutional Network Analysis of Optical Micrographs for Liquid Crystal Sensors." *The Journal of Physical Chemistry C* 124, no. 28 (2020): 15152-15161. https://doi.org/10.1021/acs.jpcc.0c01942
