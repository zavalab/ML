# MD_Euler

Euler characteristic analysis of molecular dynamics simulations: acid-catalyzed reactions and self-assembled monolayers.

## Contents
- `Acid_Catalyzed_Reactions/`: notebooks and data for acid-catalyzed reactions
- `Self_Assembled_Monolayers/`: notebook and data for self-assembled monolayers

## Reference
This code accompanies the paper:
