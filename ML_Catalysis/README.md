# ML_Catalysis

Machine learning and information-space analysis for predicting catalytic activity from experimental data.

## Contents
- `MLCatalysisData/`: catalyst data and MATLAB scripts for feature extraction, PCA, information-space analysis, and model errors

## Reference
This code accompanies the paper:

Alexander Smith, Andrea Keane, James A. Dumesic, George W. Huber, and Victor M. Zavala. "A machine learning framework for the analysis and prediction of catalytic activity from experimental data." *Applied Catalysis B: Environmental* 263 (2020): 118257. https://doi.org/10.1016/j.apcatb.2019.118257
