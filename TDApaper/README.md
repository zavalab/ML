# TDApaper

Examples of topological data analysis (TDA) in chemical engineering. Each notebook reproduces one example:
- `Pointcloud_Example.ipynb`: persistent homology of point clouds
- `Diffusion_Scalar_Fields.ipynb`: scalar fields from diffusion
- `State_Space_Analysis.ipynb`, `State_Space_Windowed.ipynb`: dynamic state spaces
- `MD_Simulation_Analysis.ipynb`, `H2O_DMMP.ipynb`: molecular dynamics simulations of water and DMMP (data in `MD_Training_Sets.zip`, `MD_Test_Sets.zip`, `Water/`, `DMMP/`)
