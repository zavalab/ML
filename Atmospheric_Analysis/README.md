# Atmospheric_Analysis

Riemannian-geometry analysis of multi-site, multi-pollutant air quality data from Beijing (NO₂, variograms, holiday/weekend/weekday patterns).

## Contents
- `NO2_Analysis.ipynb`: NO₂ analysis
- `variogram_example.ipynb`: variogram example
- `holiday_weekend_weekday_analysis.ipynb`: holiday, weekend, and weekday patterns
- `Data/`: hourly pollutant data for Beijing and station locations
